# 機会探索

まだ何を作るか決まっていない時に読む。目的は、**技術が印象的な機会**ではなく、**技術が意味のある・観測できる・守れる価値を生む機会**を見つけること。

## 1. 痛みの発見

繰り返し発掘すべき問い。

- 何が繰り返し失敗するか / 何に時間がかかりすぎるか
- 何が熟練者の観察を必要とするか / **本人には見えないものは何か**
- 何が忘れられるか / 今日測れないものは何か
- 何が高価な機材を要求するか / 何が指導者によってバラつくか
- 何が人をやめさせるか / 何が事業から顧客や収益を失わせるか
- 何が繰り返しの人手レビューを必要とするか / 何が安全・品質・法令リスクを生むか

**最も強い痛みの型:** 「熟練者なら見えるが本人には見えない」かつ「熟練者の時間が足りない」。ここに身体×カメラの技術が最も自然に嵌まる。

## 2. 現在の代替手段

今どう解決されているかを必ず特定する。鏡、指導者の観察、スマホ動画、手書きメモ、ビデオ通話、ウェアラブル、回数カウント、人手レビュー、汎用トレーニングアプリ、印刷カリキュラム、記憶、あるいは無対策。

代替手段が次のいずれかであるほど機会は強い。

遅い / 高い / バラつく / アクセスできない / 繰り返せない / 拡張できない / 理解しにくい / 希少な専門性に依存する

**逆に警戒すべき兆候:** 代替手段が「スマホで撮って見返す」で、本人がそれに不満を持っていない場合。この時、プロダクトは「もっと良い動画プレイヤー」にしかならない。

## 3. 観測可能性

動きの技術がその課題を実際に観測できるかを判定する。**観測できない変数について自動フィードバックを提案してはいけない。**

- 重要な挙動は視覚的に観測できるか / 1つの角度から見えるか
- 時間的な順序が重要か(なら単一フレーム判定は不可)
- 奥行きが重要か / 力が重要か(カメラでは力は見えない。加速度から推定するしかない)
- 接触が重要か / 内的感覚が重要か(**痛み、力み、意識の向け方はカメラに映らない**)
- 物体との相互作用があるか / 別のセンサーが必要か
- 観測に熟練者の解釈が必要か(必要なら、その解釈をどこから調達するかが最大の設計問題になる)

**最も多い失敗:** 見えるもの(手足の位置)を測り、価値のあるもの(重心の乗り方、脱力、意図)を測っていない。

## 4. 行動を変えられるか

観測だけでは価値にならない。検出できることが、次のいずれかに繋がるかを判定する。

修正 / 判断の変化 / 新しい練習行動 / より安全な手順 / 速いレビュー / より良い指導 / より良い連携 / 測れる改善

**検出できるが行動を変えない差は、プロダクトを正当化しない。**「あなたの肘の角度は12度ずれています」は検出であって指導ではない。何をどうすればよいかへ翻訳できて初めて価値になる。

## 5. 機会の評価

数値の厳密さを装わず、比較のために使う。

```
痛みの頻度 × 痛みの深刻さ × 観測可能性 × 行動変容可能性 × 信頼 × 支払意思
  − 導入摩擦 − 誤判定コスト − 展開の複雑さ
```

各項目の見方。

- **信頼** — 指導者がこのシステムの出力を信じるか。**一度の明らかな誤判定で、専門家はシステム全体を捨てる。**この項目は他より重く効く
- **誤判定コスト** — 間違えた時に何が起きるか。作品なら「変な絵が出る」で済むが、指導なら「間違ったフォームを強化する」「怪我をする」になる。コストが高い領域ほど、確信が持てない時に黙る設計が必要
- **導入摩擦** — クラス中に2分以上かかる準備は、実際には使われない。設置、キャリブレーション、アカウント作成、説明のすべてが摩擦
- **支払意思** — 「使ってみたい」と「お金を払う」の間には深い溝がある。誰の予算から出るかまで特定して初めて意味がある

## 6. 誰が払うのかを詰める

身体×学習の領域では、使う人と払う人が分かれるのが常態である。

| 構成 | 使う人 | 払う人 | 成立条件 |
|---|---|---|---|
| 個人向けアプリ | 学習者 | 学習者 | 継続する動機が自己完結している。習慣化の設計が生命線 |
| 保護者課金 | 子ども | 保護者 | **保護者に上達が見えること**が価値。子どもの体験より報告の質が効く |
| 道場・スタジオ導入 | 生徒と指導者 | 経営者 | 継続率か新規獲得か単価に効くことを示せる。指導者が味方であること |
| 指導者向け道具 | 指導者 | 指導者/道場 | 指導者の時間を実際に節約する。生徒には見えなくてよい |
| 学校・法人 | 生徒/従業員 | 組織 | 予算年度、稟議、同意、プライバシーが導入の主戦場になる |

**指導者は門番である。**指導者を間違っているように見せるプロダクトは、どれだけ技術が正しくても拒絶される。指導者を置き換えるのではなく増幅する設計にすること。

## 7. 機会探索の出力

1. 対象領域と、その中で選んだ焦点
2. 価値の高い痛み(3〜5個、頻度と深刻さの根拠つき)
3. 現在の代替手段と、その不満点
4. そのうち動きの技術で観測可能なもの
5. 行動変容に繋がるもの
6. 有望なプロダクト方向(形式まで含めて)
7. 払う人と、その予算の出所
8. 導入リスクと誤判定コスト
9. **推奨する1つの機会**と、その理由
10. 最も安く信頼できる検証計画

**すべてを並べて終わらない。**推奨を1つ出す。
