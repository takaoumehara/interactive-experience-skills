# 身体・動きの作品化 — ダンス、武術、パフォーマンス

<!-- volatile: 2026-07 — モーション取得手法の比較、対応 fps、端末とセンサーの性能。 -->

身体を扱う作品の成否は、トラッキング精度ではなく**動きの何を読み取り、何に変換するか**で決まる。関節座標を線で描くだけの作品が量産されるのは、座標しか見ていないからである。

## 1. 最初に決めること — 誰の体験か

身体作品には3種類の受け手がいて、最適解が全く違う。混同すると全員に中途半端になる。

| 受け手 | 求められるもの | 設計の焦点 |
|---|---|---|
| **演者** | 身体の延長として感じられること | 遅延、予測可能性、稽古での再現性 |
| **その場の観客** | 演者の技量と映像の関係が「見える」こと | 因果の可読性、スケール、席からの視認性 |
| **映像の視聴者** | 一発の構図の強さ | カメラ画角、編集、尺(15〜60秒) |

**判断:** 演者最優先なら遅延と再現性に全予算。映像視聴者優先なら、リアルタイムである必要すらないかもしれない(収録データの後処理で圧倒的な質を出す方が正しい場合がある)。「リアルタイムでやる意味があるか」を毎回問う。

## 2. 身体版フレームワーク

コアの Trigger → Interpretation → Response → Transformation → Residue を、身体作品用に展開したもの。企画の骨格として使う。

**Practice → Signal → Quality → Mapping → Feedback → Evolution**

- **Practice(実践)** — 元になる身体の営み。空手の組手、コンテンポラリーの即興、茶道の所作。**ここから始めるのが最も重要。**センサーから始めた企画は必ず浅くなる
- **Signal(信号)** — システムが実際に観測できるもの(関節位置、手首の軌跡、腰の回転、接地、音)
- **Quality(質)** — 信号から抽出される意味のある性質(方向、決断、速度、回復、リズム、重さ)
- **Mapping(写像)** — その質がメディアをどう変えるか
- **Feedback(フィードバック)** — 演者がその瞬間に何を知覚するか
- **Evolution(展開)** — 行為の蓄積がより大きな変化へどう育つか

例(武術のコンビネーション): Practice=連続技 / Signal=姿勢・手首軌跡・腰の回転・タイミング / Quality=方向、踏み込みの決断、速度、残心、リズム / Mapping=打撃が場を切り裂き、圧縮し、方向を変える / Feedback=即時の視覚的破断と空間音響 / Evolution=技の反復がその人固有の視聴覚的作曲になる。

**写像は、主体性を持てる程度に理解可能で、発見が続く程度に豊かでなければならない。**単純すぎると操作説明書になり、複雑すぎるとランダムに見える。

### 4層に分けて実装する

認識と芸術的解釈を混ぜない。混ぜると、表現を変えるたびに認識系を作り直すことになる。

| 層 | 内容 | 例 |
|---|---|---|
| **認識層** | 生の観測 | 手が左から右へ高速に移動した |
| **解釈層** | 意味づけ | この動きは「斬り」である(方向・速度・決断) |
| **創造層** | 表現 | 斬りが視覚の場を切断する |
| **体験層** | 蓄積 | 場が切断を記憶し、反復によって変質していく |

この分離により、**認識系を再学習させずに表現だけを改良できる。**個人開発では特に効く(表現の試行回数が質を決めるため)。

## 3. モーション取得の選択

| 手法 | 精度 | 遅延 | コスト | 適する場面 | 弱点 |
|---|---|---|---|---|---|
| 単眼カメラ + 姿勢推定 (MediaPipe/RTMPose等) | 中(2D高、3Dは推定) | 20〜50ms | ほぼ0 | Web/モバイル配布、正面向きの動き | 自己遮蔽、床技、高速動作、絶対スケールなし |
| ステレオ2台 | 高 | 30〜60ms | 低 | 床技・組技・回転を含む動き | キャリブレーション、同期 |
| 深度カメラ | 中〜高 | 20〜40ms | 低〜中 | 屋内、近距離、暗所 | 屋外・強光に弱い、範囲が狭い |
| iPhone ARKit ボディトラッキング | 中 | 低 | ほぼ0 | 1人、機動的な撮影、屋外 | 1人のみ、正対前提。**OSバージョンにより機能不全の報告がある。採用前に実機で検証すること(`current.md`)** |
| IMUスーツ | 高 | 10〜30ms | 中 | 遮蔽なし、暗転中も動作、舞台向き | 位置ドリフト、装着時間、磁気干渉 |
| 光学式マーカー | 最高 | 5〜15ms | 高 | 高精度が作品の核である場合 | 設営、コスト、マーカー衣装 |

**2台構成の現在地:** カメラ2台以上から三角測量で3D関節を得るオープンソースのパイプラインが実用段階にあり、**「3D関節位置が欲しいだけなら深度カメラを買うより安く・確実」**な局面が増えた。深度カメラが要るのは手前の遮蔽やシルエット分離が必要な場合。具体的なツール名と入手性は `current.md`。

**選定の勘所:** 舞台上での暗転や照明変化があるならIMU一択に近い(カメラは照明に殺される)。武術の高速打撃は光学式かIMU。Web配布が目的なら単眼一択で、その制約内で成立する動きを選ぶ。

**高速動作の落とし穴(最重要):** 突き・蹴り・回転は、30fps・ローリングシャッターのカメラでは**モーションブラーで消える**。推定が破綻するのは技術力の問題ではなく物理の問題。対策は ①60〜120fps撮影 ②シャッタースピードを上げる(=大幅に明るい照明が必要) ③グローバルシャッターのカメラ ④IMUに切り替える。武術案件では、この照明とfpsの要件を企画の最初に確定させる。

## 4. 動きから何を読み取るか — 座標の先へ

関節位置(x, y, z)は素材の最下層にすぎない。以下を抽出できると、表現の解像度が桁で変わる。

**運動量的な特徴**
- 速度、加速度、**ジャーク**(加速度の変化率 = 動きの「鋭さ」。打撃や切れのある動きの検出に極めて有効)
- 重心(COM)の位置と軌跡、支持基底面との関係 → 安定/不安定、崩し
- 運動連鎖 — 足→腰→肩→手先へ力が伝播する時間差。武術の質はここに出る
- 角運動量、回転の軸

**形態的な特徴**
- 収縮/伸展(身体の占める体積)、対称/非対称
- キネスフィア(手足が届く球体空間)のどこを使っているか — 近接/中間/遠隔
- 開き/閉じ(胸郭の向き)、上下の重心高

**時間構造の特徴**
- フレーズの切れ目(動きの始点・終点)、アクセントの位置
- **静止**。動きだけを検出する設計は、最も重要な瞬間である「静止」を捨てている
- 予備動作 → 主動作 → 残心 の三段構造
- 反復と逸脱(同じ動きの中の微差)

### Laban Effort — 動きの「質」を4軸で記述する

座標では取れない「どう動いたか」を記述する古典的枠組み。マッピング設計の共通言語として実務価値が高い。

| 軸 | 両極 |
|---|---|
| **Weight(重さ)** | Light 軽い ↔ Strong 強い |
| **Time(時間)** | Sustained 持続的 ↔ Sudden 突発的 |
| **Space(空間)** | Indirect 間接・多方向 ↔ Direct 直接・一方向 |
| **Flow(流れ)** | Free 解放 ↔ Bound 抑制 |

組み合わせが8つの基本動作になる: Float(軽・持続・間接)、Punch/Thrust(強・突発・直接)、Glide(軽・持続・直接)、Slash(強・突発・間接)、Dab(軽・突発・直接)、Wring(強・持続・間接)、Flick(軽・突発・間接)、Press(強・持続・直接)。

**実装への落とし方:** Weight ≈ 加速度の大きさと重心の沈み、Time ≈ ジャークと動作の立ち上がり時間、Space ≈ 軌跡の曲率と方向の分散、Flow ≈ 動きの連続性(停止の頻度と減速の仕方)。これらを0〜1に正規化して視覚パラメータへ写像すると、「速い/遅い」だけの単純なマッピングを一気に超える。

### 武術に固有の材料

- **間(ま) / 間合い** — 対戦者との距離と時間の駆け引き。2人の距離を主変数にするだけで、突き1発より遥かに豊かな表現になる
- **極め(きめ)** — 打撃が極まる一瞬の全身緊張。加速度のピークではなく、その直後の急停止(負のジャーク)で検出できる
- **残心(ざんしん)** — 技の後の緊張の持続。ここに余韻の演出を置くのが最も美しい。技が当たった瞬間に爆発させるのは誰でもやる
- **呼吸と気合** — マイクで拾える。視覚より音の情報量が多いことがある
- **崩し** — 重心が支持基底面から外れる瞬間
- **型の再現性** — 同じ型の複数回の差分を可視化すると、修練そのものが作品になる(教育用途にも展開できる)

### ダンスに固有の材料

- **フレージング** — 音楽に対して先行/同期/遅延のどれか。「音に合っている」ことより「どうずらしているか」が表現
- **床の使用** — フロアワークは単眼カメラを必ず破壊する。作品に床技があるなら取得手法の選択が先に決まる
- **アンサンブル** — ユニゾン(揃い)、カノン(ずらし)、対位。**個人ではなく関係を読む**。2人の同期率、距離、鏡像度合いは強力な変数
- **空間軌跡** — 舞台上のパスワーク。フロアパターンそのものを描画する

## 5. マッピング設計 — 陳腐化を避ける原理

**最も避けるべき既視感:** 身体に軌跡(トレイル)を引く、シルエットをパーティクルにする、骨格線を光らせる。悪くはないが、2010年頃から無数にある。ここから抜けるための7つの方向。

1. **時間をずらす** — 現在の動きに即応させず、数秒前の自分、あるいは前回の稽古の自分と共演させる。同一人物の複数時制が同じ空間に立つ
2. **身体を消して環境を動かす** — 身体には何も描かない。空間・光・音・物体だけが反応する。演者が「見えない力を持っている」ように見える(Rain Room型の強度)
3. **蓄積する** — 一回の動きが消えず、空間に痕跡として残り、次の動きと干渉する。10分後の空間が、その10分の記録になっている
4. **別の物質に変換する** — 動きを水・煙・砂・布・群れ・音として翻訳する。人体の形を保たない方が、動きの質は逆によく伝わる
5. **反転させる** — 激しく動くほど静まり、静止した時に最大の反応が起きる。演者に新しい身体的課題を与えるマッピングは、それ自体が振付になる
6. **抵抗を持たせる** — システムが素直に従わない。慣性、疲労、遅れ、拒否。**演者とシステムが対等な共演者になる**のは、システムが意志を持つように見える時
7. **関係を読む** — 1人ではなく2人以上の関係(距離、同期、視線、接触)を主変数にする。武術の対人稽古、デュエットに直結する

**設計の判定基準:** そのマッピングは「この人がこう動いた」ことを伝えているか、それとも「システムがこう反応した」ことを見せているだけか。後者はデモであって作品ではない。

## 6. 遅延の設計 — 演者は容赦なく気づく

- **演者が身体の延長として感じる境界: 入力から出力まで合計 50ms 前後。**訓練された身体は 30〜40ms の差を検出する。観客は 100ms でも気にならないが、演者は破綻を感じる
- **目標値の階層:** 50ms未満=楽器のような即時性 / 50〜100ms=多くの視覚的インタラクションで十分応答的 / 100〜200ms=知覚されるが、ゆるやかな表現や意図的な遅延効果なら許容 / 200ms超=創造的な理由で正当化するか、予備動作で先読みさせる設計が必須
- **リズミカルなダンス、打撃、受け、高速なジェスチャーでは、遅延そのものが作品の質である。**視覚的な複雑さで遅さを隠そうとしない
- 経路ごとの内訳を必ず見積る: カメラ露光・転送(16〜33ms) + 推論(10〜30ms) + アプリ処理(数ms) + レンダリング(16ms) + 表示遅延(10〜20ms、プロジェクターとディスプレイで差が大きい)
- **短縮の勘所:** 高fps撮影(60/120fps)で最初の16〜33msを削るのが最も効く。次に軽量モデル。表示側では、プロジェクターやテレビの「映像処理モード」をOFF(ゲームモード)にするだけで数十ms縮むことがある
- **遅延を隠す設計:** 全要素を即応させる必要はない。即応する層(輪郭、音)と、ゆっくり応じる層(環境、色調)を分ける。人は最速の層で応答性を判断する
- **予測を使う** — 速度から数フレーム先を外挿すると体感遅延を減らせる。ただし急停止で行き過ぎるので、極めや静止のある動きでは慎重に

## 7. 稽古と本番の設計

技術者が最も軽視し、演者が最も必要とすること。

- **稽古モードを最初に作る。**演者はシステムと共に練習する必要がある。本番前日に初めて触らせるのは、共演者に本番当日初めて会わせるのと同じ
- **再現性を保証する。**同じ動きが同じ反応を返さないと稽古が成立しない。乱数を使うなら、シードを固定できるモードを用意する
- **キャリブレーションを1分以内に。**演者ごと・公演ごとに必要になる。長いキャリブレーションは現場で必ず省略され、精度が落ちる
- **演者への合図。**システムの状態(認識中/ロスト/次のシーン)を、観客に見えない形で演者に伝える手段(足元の小さなライト、イヤモニ、音)
- **失敗時の縮退。**トラッキングが落ちても公演は止まらない。事前収録のデータへ自動フォールバック、あるいは音楽だけで成立する区間を用意する
- **収録を必ず残す。**モーションデータを毎回保存する。後の作品化、映像化、再演、教育コンテンツすべての原資になる

## 8. 協働のしかた

ダンサー・武術家は、技術者が持っていない身体知を持っている。**マッピングを決めてから演者を呼ぶのではなく、演者と一緒にマッピングを決める。**

進め方: ①演者に普通に動いてもらい、そのデータを記録する ②抽出できる特徴量を演者に見せ、「どれが自分の動きの本質に近いか」を聞く ③その特徴量を軸に粗いマッピングを作り、演者に試させる ④演者が「もっとこうしたい」と言った時に、それが振付の変更かシステムの変更かを一緒に判断する。

この往復を3回以上できるかが作品の質を決める。1回で決めた作品は、演者が「システムに合わせて動いている」ように見える — 観客はそれを敏感に見抜く。

## 9. 出口の設計

身体作品は公演で終わらせるともったいない。同じ素材から複数の出口を作れる。

- 公演/ライブパフォーマンス
- 単体の映像作品(縦型15〜60秒の切り出しを最初から設計しておく)
- インスタレーション化(収録データを常設で再生・干渉させる)
- 参加型への展開(観客が同じシステムで自分の動きを試せる)
- 教育・練習ツール(型の可視化、フォーム比較、上達の記録) — 事業化の道が最も見えやすいのはここ
- データそのものの作品化(プリント、彫刻、NFT以外の物理出力)

## 10. 元の実践への敬意

ダンス、武術、スポーツ、儀礼、工芸は、モーションデータの供給源ではない。そこには意図、律動、重さ、緊張、解放、均衡、方向、間、呼吸、予兆、精度、危険、規律、空間との関係、他者の身体との関係が含まれている。

企画時に必ず判断する — その実践の中で**何が意味を持つのか**を特定し、それを **保存する / 増幅する / 抽象化する / 変換する / 可視化する / 可聴化する / インタラクティブにする / 集合的にする** のどれにするか。

**判定基準:** そのシステムは、肉眼では即座に知覚できない何かを、その動きについて明らかにしているか。していなければ、実践を装飾として消費しているだけである。

具体的な失敗の形: 型の意味を無視して見た目の派手な瞬間だけ切り取る。文化的文脈のある所作を、無関係な世界観の素材として使う。熟練者が価値を置く要素(残心、間合い、脱力)を捨てて、素人にも分かる要素(速さ、大きさ)だけを取る。演者を「動く入力装置」として扱い、共同制作者として扱わない。

武術や伝統芸能を扱う場合は、その実践者に「これは自分たちのやっていることを正しく見ているか」を早い段階で確認する。技術的な精度より、この確認の方が作品の格を決める。

## 11. 身体メディア・ディレクションの出力構成

スケールP(パフォーマンス)または身体入力が中心の企画では、選んだモードの構成に次を重ねる。

1. **元の動きの意味** — その実践において何が価値なのか
2. **捉えるべき動きの質** — 全信号ではなく、意味のある質を選ぶ理由とともに
3. **インタラクションとメディアの写像** — Practice → Signal → Quality → Mapping → Feedback → Evolution
4. **演者のフィードバックループ** — 演者が何を感じ、どう振る舞いを変えるか
5. **観客の体験** — 行為と変化の関係が客席から理解できるか
6. **センシング方式** — 手法選定と、その動きに対する妥当性(遮蔽・速度・照明)
7. **視聴覚の言語** — 既視感を避ける原理のどれを使うか
8. **プロトタイプの稽古** — 演者と行う最初の1回で何を確かめるか
9. **実践を見世物に落とすリスク** — 何を失う危険があり、どう防ぐか
