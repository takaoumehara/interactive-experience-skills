# 手法カタログ — 公開作品から観察できる手法と、その適用

<!-- volatile: 2026-08 — スタジオの存続と体制、代表作、客単価と損益分岐の相場。買収・解散・事業転換が起きる。身体インタラクション系の現行プレイヤーと製品は特に動きが速いため、営業資料に使う前に必ず一次情報で再確認する。 -->

**このファイルの読み方 — 3つの規則。破ると事故になる。**

**規則1: スタジオ名は帰属主張ではなく参照作例のポインタである。**括弧内の名前は「この手法を体感したければこのスタジオの公開作品を見よ」という意味であり、「そのスタジオがこの方法で作っている」という主張ではない。非公開の制作手法や内部ノウハウは誰も知らない。出力では **「A社的」と書かず、手法と原理に変換して書く。**

**規則2: 数値はすべて計画開始点の目安であり、業界データではない。**ここにある輝度・単価・回転率・比率は、見積もりの初期値として置くための数字である。**施主・投資家・記事に「業界水準では」として提示してはいけない。**案件条件で必ず再検証し、出力時は「初期見積の目安。実測・実見積で確定させる」と添える。

**規則3: 名前を飾りに使わない。**ここにあるのは「名前」ではなく「盗める手法」。プロジェクトに適用できる項目だけを、適用理由とともに引用する。列挙は無価値。

**規則4: 「世界初」を名乗らせない。**この分野は先行が厚い。新規性の主張は、それを知っている相手 — つまりミュージアムやギャラリーの担当者 — からの信頼を一撃で失う。**逆に、系譜を語れると一気に信頼される。**代わりに書くべきは「先行はここにある。我々の差分はこれ」という形。差分は、対象・距離・器・時間軸・出口のいずれかで言えることが多い。

各項目は **手法名 / 原理 / 使いどころ / 実装ヒント** で構成。原理と使いどころは公開作品から観察可能な範囲。実装ヒントは一般的な制作技術での再現方法であり、実物の構成とは限らない。

## 生成・アルゴリズミック系

**リアルタイム生成による非再現性 (TeamLab)**
- 原理: 映像を再生ではなく毎フレーム生成。来場者の干渉が系全体に波及し、同じ瞬間が二度と起きない
- 使いどころ: 滞在時間を伸ばしたい常設展示。リピーター獲得。「私だけの瞬間」というSNS動機
- 実装: パーティクル/フロッキング/反応拡散系をGPUで。干渉入力はLiDAR/深度カメラ。決定論的シードを捨てて実時間を種にする

**データ彫刻 (Refik Anadol Studio)**
- 原理: 実データ(気象、脳波、都市データ、アーカイブ画像)をAIで潜在空間化し、その航行を可視化する
- 使いどころ: 企業の保有データに物語性を与えたいコーポレート案件。美術館級の権威性が欲しい時
- 実装: StyleGAN/Diffusionの潜在空間補間、またはポイントクラウドの流体化。前処理パイプラインの工数を必ず見積る(制作費の3-5割がデータ整備)

**自然系シミュレーションと身体 (Marshmallow Laser Feast)**
- 原理: 呼吸・心拍・視線など生体データを自然のスケール(森、血流、大気)に接続する
- 使いどころ: ウェルネス、環境テーマ、1人〜少人数の深い体験
- 実装: 心拍センサー(BLE)、呼吸ベルト、アイトラッキング → 粒子系/ボリュームレンダリングへマッピング

## 錯視・視覚インパクト系

**アナモルフィックLED (d'strict)**
- 原理: コーナー型LEDに視点固定でレンダリングした3D映像を貼ると、特定視点から飛び出して見える
- 使いどころ: 屋外広告、待機列の正面、SNS拡散の起爆点。「1枚の動画で伝わる」画が必要な時
- 実装: 会場の主要撮影位置を先に決め、そのカメラ行列でUnreal/Unityからレンダリング。ピッチはP2.5以下推奨(近接視認時)。斜め視点からは歪んで見えることを施主に事前合意させる

**建築マッピングの構造同期 (Obscura Digital / Seeper)**

> Obscura Digital は2017年に Madison Square Garden 社に買収され、以降の活動は Sphere(Las Vegas)の設計へ吸収されている。参照するのは公開済みの旧作(Empire State Building、Sydney Opera House 等)であり、独立したスタジオとして発注・接触できる相手ではない。
- 原理: 建物の窓・柱・装飾のジオメトリに映像の動きを一致させ、建築自体が動く錯覚を作る
- 使いどころ: ファサードマッピング、歴史的建造物、周年イベント
- 実装: フォトグラメトリで実測メッシュ→UV展開→構造線に沿ったアニメーション。輝度は環境光に勝つため20,000lm級を複数台ブレンド

## 物語・空間系

**環境ストーリーテリング (Meow Wolf)**
- 原理: 説明せず、空間に散りばめた手がかり(手紙、家具、隠し扉)で物語を発掘させる。物語は順不同で成立させる
- 使いどころ: 探索型常設施設、再訪動機の設計、ファンコミュニティ形成
- 実装: 物語をノード群として設計し、どの順で発見しても意味が通る非線形構造にする。隠し要素は発見率で層を分ける(誰でも見つかる層 / 探した人が見つかる層 / ほぼ誰も見つけない層)。**最下層は「見つけた人がSNSで語る」ための層であり、体験の理解に必須の情報を置かない**

**都市・大規模動線の演出統合 (Moment Factory)**
- 原理: 数百m〜kmスケールの動線全体を1つのショーとして設計。ゾーンごとの緩急(高刺激→休息→高刺激)
- 使いどころ: ナイトウォーク、空港・駅、テーマパーク
- 実装: ゾーンをBPMと照度で設計(例: 導入60BPM/50lx → ピーク120BPM/フルカラー)。ゾーン間トランジションに30-60秒の減圧区間を必ず入れる

**名画・アーカイブのイマーシブ化 (Culturespaces)**
- 原理: 既存IP(名画等)を全周投影+音楽で再編集。コンテンツ制作リスクが低く集客が読める
- 使いどころ: 商業施設の集客装置、地方の文化施設。IPライセンスの確認が最初の仕事
- 実装: 30-40分ループ、立ち見+着席混在、1時間あたり回転1.5回転で収容計算

**テーマパーク型の運用設計 (Thinkwell Group)**
- 原理: 体験品質はショーだけでなくキュー(待機列)・キャスト・保守性で決まる
- 使いどころ: 常設・高スループット施設全般。企画の最終監査に必ずこの視点を通す
- 実装: 待機列自体を体験化(プリショー)。1日の想定来場者から逆算: スループット = 定員 × (60/体験分数) × 稼働率0.85

## 実験・身体系

**身体とシステムの拮抗 (Rhizomatiks)**
- 原理: ダンサー/観客の動きとマシン(ドローン、レーザー、ロボット)をリアルタイム同期させ、人機の境界を曖昧にする
- 使いどころ: パフォーマンス、ブランドの技術力提示、一夜限りのライブ
- 実装: モーキャプ(光学式 or IMUスーツ)→OSCで照明/映像/機構へ。遅延予算は全経路で50ms以下。本番系と同一構成のリハ環境を必ず用意

**環境応答する彫刻的インスタレーション (Random International)**
- 原理: 「Rain Room」型 — 単一の強いルール(雨はあなたを避ける)だけで成立する体験。説明不要の即時理解
- 使いどころ: コンセプトを1行で言える案件。アート文脈での批評性が必要な時
- 実装: ルールを1つに絞り、検出精度に全予算を注ぐ。検出失敗が体験の失敗に直結するため冗長センサー構成(例: 深度カメラ×2系統+圧力床)

**建築・メカトロニクス統合 (ART+COM)**
- 原理: 物理オブジェクト(金属球、可動パネル)の群制御で「デジタルの動きを物質で」表現
- 使いどころ: 企業ロビー常設、静的空間に生命感を入れたい時。映像より経年で陳腐化しにくい
- 実装: ステッピングモータ群+産業用バス(CAN/EtherCAT)。保守契約とスペアパーツを初期見積に含める

## 日本のデザインエンジニアリング系

**プロトタイプ駆動の体験設計 (Takram)**
- 原理: 議論より動くプロトタイプ。ビジョンとエンジニアリングを1チームで往復する
- 使いどころ: 要件が曖昧な初期フェーズ。施主説得用のPoC
- 実装: 1-2週間で「体験の核」だけ動くデモを作り、それを仕様書の代わりにする

**モーショングラフィックスの空間拡張 (WOW)**
- 原理: 2Dモーションデザインの精度(イージング、タイポグラフィ)をそのまま空間に持ち込む
- 使いどころ: ブランドの世界観が厳格な案件、プロダクトローンチ
- 実装: After Effectsの言語で設計→TouchDesigner/Notchでリアルタイム化。ブランドのイージングカーブを共通ライブラリ化

**参加型・遊びのメカニクス (PARTY / 1→10)**
- 原理: 体験を「遊び」として設計 — 明確なゴール、即時フィードバック、スコア/ランキング
- 使いどころ: 商業イベント、ファミリー層、滞在時間より回転数が必要な案件
- 実装: 1プレイ60-120秒、結果のシェア画像を自動生成(SNS拡散の実装レベルの担保)

**伝統・自然素材との融合 (NAKED / Utsubo)**
- 原理: 花、霧、香り、和紙などの実素材とプロジェクションを重ね、デジタル単体では出ない質感を作る
- 使いどころ: 日本文化文脈、ラグジュアリーブランド、寺社・庭園会場
- 実装: 素材側の反射率・透過率を先に実測し、それに合わせて映像の輝度・彩度を設計。生花は保守コスト(週次交換)を見積る

## 身体インタラクションの系譜 — 提案前に必ず知っておく

**身体を入力にする作品を提案するなら、ここを知らずに出てはいけない。**「動きの質を可視化します」は20年以上前から探究されているテーマであり、知らずに言うと再発明に見える。

**動きの「質」を抽象彫刻にする (Memo Akten《Forms》/ Klaus Obermaier《Apparition》)**
- 原理: 骨格を描かず、速度・方向・強度・身体のボリュームといった**運動の質的特徴**を計算し、それを映像へ割り当てる。身体と周辺空間の隠れた関係を見せる
- 使いどころ: 座標を線で結ぶ段階から抜けたい全案件。`movement.md` §4 の「質」の実例
- 実装: 層2(Motion Features)を厚くし、層4では身体の形を保たない

**声・手を物体化し、それを身体で再操作する (Golan Levin + Zachary Lieberman《Messa di Voce》《Manual Input Sessions》)**
- 原理: 音や手の形をリアルタイムに可視化して**物体として画面に置き**、その物体を身体で再操作すると音が鳴る、という循環を作る
- 使いどころ: 楽器的な体験。映像と音に一貫した因果を持たせたい時
- 実装: 生成物に状態を持たせ、次の入力の干渉対象にする(`movement.md` §5-3 の蓄積)

**影・分身を身体から切り離す (Scott Snibbe《Shadow》)**
- 原理: 来館者の影が身体から離れて記録・反復され、来館者自身が映像を作る側になる
- 使いどころ: 説明ゼロで成立する参加型。時間をずらす演出(`movement.md` §5-1)の原型

**身体追跡による抽象生命体・環境融合 (Universal Everything / teamLab)**
- 原理: 全身の動きを抽象的な生命体や環境の変化に翻訳し、来場者ごとに異なる結果を生む。大画面・室内距離・全身シルエットが主戦場
- **使いどころの注意: ここは最も層が厚い。**「全身シルエットが抽象生命体になる」作品を最初に作ると、最も装備の薄い状態で最も強い相手の土俵に立つことになる
- **構造的に空いているのはその逆側** — 近距離(顔・指・口・呼吸)、URLで即座に始まる配布、音が映像と同じ物理から出ていること。`feel.md` §5 の距離の選択がそのまま戦略になる

**運用基盤としての内製ランタイム (Moment Factory / Ars Electronica Futurelab)**
- 原理: 大型体験の制作・会場機器制御・来場者センシングを統合する自社ランタイムを持つ。模倣が難しいのは作品ではなく**この運用層**
- 使いどころ: 常設・巡回で複数案件を回す段階に入った時の到達目標。`solo-scale.md` §12 の段階3〜4に相当

**カメラで動作を評価する製品群(スポーツ・ヘルスケア)**
- 原理: 姿勢推定に競技固有の物体検出・3D復元・バイオメカニクスを積み、回数・速度・角度・正誤を返す
- **使いどころ: 直接の競合ではなく境界の確認に使う。**彼らが強いのは「正しい/間違い、角度、回数」。**弱いのは「詩的で、続けたくなる感覚的フィードバック」**。上達支援側の案件は `movement-learning-system-designer` の管轄
- **注意:** この領域は特許が存在する。臨床・医療に寄る製品まで進むなら専門家による調査が要る

## 常設・商業ギャラリー系

**常設イマーシブの興行モデル (Superblue / ARTECHOUSE)**
- 原理: アーティストとレベニューシェアし、チケット興行として常設運営する
- 使いどころ: 事業計画段階。初期投資回収モデルの参照
- 実装: レベニューシェア比率、会場賃料、アーティスト費を先に固定してから収容設計に入る。光熱費とGPU更新(3年)を運営費に必ず計上
- **事業数値の初期値(根拠のない置き数字。実地で必ず差し替える):** 都市部で客単価2,500〜4,500円、損益分岐は月1.5〜3万人規模。**この2つは感度分析の出発点としてのみ使う。**実在施設の公表値・IR・現地のチケット価格に置き換えるまで、事業計画の根拠として提示してはいけない

**企業体験センター (HUSH)**
- 原理: 企業のデータ・文化を空間化し、来客・採用・社内文化の3方向に効かせる
- 使いどころ: B2B案件、本社ロビー、ショールーム
- 実装: CMSで非エンジニアが更新できる設計にする(納品後に死ぬ展示の最大要因はコンテンツ更新不能)

**大規模商業空間の量産品質 (Wonderlabs / Mantong Digital)**
- 原理: モジュール化されたインタラクティブ装置を組み合わせ、コストを抑えて面積を埋める
- 使いどころ: 予算制約の強い商業施設、地方案件
- 実装: 既製インタラクティブモジュール+オリジナル演出1-2点の「主役と脇役」構成で予算配分(主役に6割)
