## 1. 姿勢推定 — 何を起点にするか

| 用途 | 2026年7月の解 | 注意 |
|---|---|---|
| Web/モバイルでオンデバイス | **MediaPipe Tasks**（`@mediapipe/tasks-vision` 1.0.0, 2026-07）| Web側は活発。**GPUデリゲートはWebGL2でWebGPUは未使用** |
| iOS ネイティブ | Apple **Vision framework** の2D/3D body pose | 2023年から実質据え置きだが動く |
| サーバ・多人数 | **YOLO26-pose**（活発）| AGPL-3.0 または商用ライセンス |
| CPU高速・低コスト | RTMPose / RTMW | 性能は健在だが **mmpose は2024年7月から更新停止**。凍結された優良資産として使う |
| 高精度オフライン解析 | ViTPose++ / Sapiens2 / SAM 3D Body | **リアルタイム不能。**事後解析専用 |
| カメラ2台で3D | **Pose2Sim / Sports2D**（2026年も活発）| 任意の2台以上→三角測量→運動学まで通る。**2台構成の最短ルート** |
| 手指 | MediaPipe Tasks の Hand Landmarker / Apple Vision の手ポーズ | 単体API時代の名称ではなく Tasks 系に統合されている |

### 設計判断が変わった点

- **iPhone の ARKit Body Tracking が機能しないという報告がある。** iOS 26.0/26.1 で `ARBodyAnchor` が有効な関節を返さない（期待89関節に対し0関節）。LiDAR搭載のPro機とApple公式サンプルで再現、2025年10月起票、**修正されたという記述は確認できていない。** → **「iPhone Proを置けば3D全身が取れる」を検証なしに前提にしない。**採用するなら実機で最初に確認し、駄目なら Vision framework / MediaPipe / 自前ONNX へ退避する 確度:中
- iPhone の **LiDAR は5世代を経てなお Pro/Pro Max 限定**。「LiDARは全ユーザーに存在しない」と仮定して設計する
- **精度の最高峰とリアルタイムが別トラックになった。**「リアルタイムで即座に返す層」と「後で高精度に解析し直す層」を最初から分けて設計する。中間で妥協した単一モデルを探さない
- **信頼度スコアはモデル固有である。**`skill-modeling.md` の「信頼度 < 0.7」のような閾値は MediaPipe を前提にした例であり、**モデルを替えたら閾値も測り直す。**他モデルの confidence と数値の意味は同じではない

## 2. 撮影機材・センサー

- **深度センサーを足す判断基準が変わった。** 3D関節位置が欲しいだけなら、**ステレオ2台＋姿勢推定＋Pose2Sim** の方が安く・買えて・足りる。深度が要るのは「手前の遮蔽やシルエット分離が必要な時」
- Azure Kinect DK は EOL。後継は Orbbec Femto Bolt（$418）/ Femto Mega（$695）だが**在庫が不安定**。ステレオの Orbbec Gemini 335 は **$264 で在庫あり**
- 高速動作（突き・蹴り・回転）の 60〜120fps 要件は変わっていない。**対応機種の条件は端末世代で変わるので、案件ごとに実機で確認する**

確度:高（直販ストアの表示価格と在庫）

## 3. モーションキャプチャの課金構造 — UXを規定する

**単眼スマホmocapは「使えるか」ではなく「秒課金にどう耐える体験設計にするか」の問題になった。**

- 代表的な単眼mocapサービスは**1人1秒あたりのクレジット課金**で、無料枠は一度きり。月$18〜48のプランで**実質的に扱えるのは月あたり数十秒〜数分**
- → **「常時記録して後で見返す」体験は経済的に成立せず、「1テイクを選んで精査する」体験しか作れない。**撮り放題かテイク選択制かというUXの根本設計を、価格構造が先に決めてしまう
- **常時記録が必要なら MediaPipe / RTMPose の自前運用一択**
- IMUスーツの価格は2024年からほぼ横ばい（スーツ単体で $1,500〜2,500 が下限帯）。**この2年の変化はハード価格ではなくソフトのサブスク化**

確度:高（公式料金ドキュメント）／IMU価格は 確度:中

## 4. オンデバイス処理の到達点

- 静止画の理解は民生GPU（6〜16GB VRAM）や高メモリのMacで実用域に入った
- **リアルタイム映像理解はまだ届いていない。**フレーム抽出方式が実態で、10分の動画に20〜30分かかる報告がある
- **道場での現実解は変わっていない:** 軽量CVで骨格・角度・タイミングを取り、ルールで判定する。VLM/LLMを叩くのは数秒に1回のまとめ生成やコメント生成に限定する

確度:中

## 5. 法規制 — 未成年・生体情報・医療機器

**これは事実整理であり法的助言ではない。**実案件では必ず専門家に確認する。ここは「何を確認すべきかの地図」である。

### 日本（道場・スクール案件に直接効く）

- **令和8年改正個人情報保護法が2026年7月17日に公布**（施行は公布から2年以内の政令日）
- **「特定生体個人情報」という新類型**が創設され、顔特徴データ等が対象になる見込み。①取扱い前の本人通知が義務 ②**オプトアウトによる第三者提供が不可** ③利用停止請求の要件緩和
- **16歳未満は原則として法定代理人の同意**が必要になり、最善の利益を優先する責務規定が新設された。**道場案件で保護者同意を前提条件に置くという既存の判断は、法的にも裏付けられた**
- **映像の学習利用は「条件を満たせば正面から適法」になった。** 統計作成・AI学習/分析目的なら要配慮個人情報を含め本人同意なしで利用可能。ただし ①提供者名・目的・概要の**事前ウェブ公表** ②用途限定を明記した**書面契約** が条件で、違反は課徴金対象。→ **「こっそり貯めて後で使う」が最も不利になり、最初から公表して正規ルートで貯める方が安全かつ有利**
- **監視すべき未確定事項: 歩容（gait）が特定生体個人識別符号に含まれるか。**政令待ち。**含まれれば「動きだけだから安全」という前提が崩れる。動作学習プロダクトにとって最重要の監視項目**

### 米国（子どもが使うプロダクト）

- **COPPA改正規則が2026年4月に全面適用。** 生体識別子（声紋・顔紋・顔テンプレート）が対象に明記され、**書面の保存方針が必須で無期限保存は禁止**、第三者開示には収集とは別個の保護者同意が必要
- Illinois BIPA はスキャン毎の損害賠償積み上げが否定され、私訴のリスクは下がった。代わりに州AGの執行が主戦場

### EU（EU展開する場合）

- 高リスク義務は2027年12月へ延期されたが、**透明性義務は2026年8月2日から適用**。感情推定・生体分類を使うなら初回接触時の告知が義務
- **職場・教育機関での感情推定は禁止**（医療・安全目的を除く）。**指導者向けに「生徒の集中度・やる気を推定する」機能を作ろうとしたら、ここに触れる可能性がある**

### 設計上の分水嶺

**「顔を撮るか」ではなく「一意識別するか／生体テンプレートを保存するか」。**骨格・角度・タイミングのみを扱い顔テンプレートを作らない設計を最初から選べば、三方で最も重い規律を同時に外せる。**これは事後に足せない設計判断である。**

### 医療機器該当性

痛み・損傷・可動域の判断をシステムにさせないという原則は変わらない。**臨床に踏み込む案件では、プログラム医療機器（SaMD）の該当性判断を技術検討より先に置く。**該当性のガイダンスは更新されうるため、案件ごとに現行版を確認する。

確度:高（法律の公布日と番号）／個別条文の逐語と政令の内容は 確度:中〜低（未確定）

## 6. 道場・スタジオの経済 — 価格設計の天井を決める

**確度: 中。**出典は道場コンサル・スクール運営系の記事であり、公的統計ではない。**地域差が大きく、実案件では必ず対象地域の実在教室の公開価格で置き換える。**それでも桁を間違えないための出発点として置く。

### 月謝の相場（日本、2026年7月時点）

| 業態 | 月謝 |
|---|---|
| 伝統武道（空手・柔道・剣道・合気道） | 5,000円前後が中心 |
| 格闘技系（柔術・キックボクシング） | 10,000円前後〜 |
| 子ども向け（種目問わず） | 2,000〜8,000円 |
| 大人向け（種目問わず） | 3,000〜10,000円 |
| ダンス 週1回・月4回（子ども） | 6,000〜10,000円 |
| ダンス 大人・プロ志向 | 10,000〜15,000円 |

入会金の慣習があり、5,000〜15,000円程度。

### プロダクト設計への含意 — ここが本題である

**この数字を「市場規模」として使わない。「価格の天井」として使う。**

- **月謝5,000円の道場に、月2,000円のツールは売れない。**サブスク価格を考える時、**月謝の1〜2割が現実的な上限**である。武道系で月500〜1,000円、格闘技・ダンス系でその倍、という帯から出発する
- **売る相手を間違えない。**生徒個人課金は母数が小さく、**解約が月謝の解約と連動する**（辞めた瞬間に両方切れる）。**道場が月謝に含めて配る形（B2B2C）の方が、単価も継続率も安定する。**個人向けに見えるプロダクトでも、契約は道場と結ぶ設計を先に検討する
- **入会金という慣習を使える。**初期費用を許容する文化が既にあるため、**初期導入費＋月額**の二段構えが受け入れられやすい。全部を月額に寄せる必要はない
- **無料で配って後から課金する設計は、この価格帯では回収できない。**単価が低いので、獲得コストをかけられない。**道場の紹介と口コミ以外の流入経路は、最初から計算に入れない方がよい**
