# マーシャルアーツ × カメラAI — 現状と余白（調査メモ）

> **このファイルはスキルではない。**原資料の保存であり、スキルへ昇格させた分は下の「スキルへ反映済み」に記載した。
> **製品名・企業名を含む記述は最も早く古くなる。**引用する前に一次情報で再確認すること。精度や採用技術についての推測は推測として扱う。

## 1. なぜ格闘技はゴルフ・テニス・バスケットより遅れているか

構造の問題であり、開発力の差ではない。

- 動きが非常に速い
- 腕や脚が身体に重なる（自己遮蔽）
- グローブや道着で手指が隠れる
- 二人が接近・接触する
- 攻撃が当たったか、威力があったかを映像だけでは測りにくい
- MMAや柔道では床上で身体が複雑に重なる

戦闘スポーツ向けの研究でも、急速な動き・遮蔽・近接した複数人への対処に、複数カメラ、3D三角測量、物理的な軌道補正まで動員している。

## 2. 実在するもの（カテゴリ別）

**試合・スパーの自動データ化**
Jabbr / DeepStrike が代表格。ボクシングやMMAの映像から、パンチ数、命中数、攻撃傾向、試合統計、自動ハイライト、判定支援を生成し、ジムや競技会向けに専用カメラへ組み込む方向で展開。
→ **これは「あなたのジャブは肘が開いています」と教える家庭用コーチではなく、「試合で何が起きたかを自動的にデータ化する」製品。**目的が違う。

**撮影してコメントが返るアプリ**
JAB AI（ボクシング、ムエタイ、キックボクシング、柔道、BJJ、レスリング等を掲げる）、Fight AI など。動作カウント、技術的な長所短所、フォームへのフィードバック、トレーニング提案。
→ 公開情報からは、使用モデル、評価基準を作った専門家の数、精度、競技専用モデルなのか汎用の映像説明が中心なのかが**分からない**。存在はするが、技術的信頼性が外から見えやすい段階ではない。**これは推測であり、断定してはいけない。**

**研究プロトタイプ**
AiShifu（空手フォームトレーナー）— カメラで関節座標を取得し、関節角度を計算、左右どちらの構えかを判定、師範による基準画像と比較、修正フィードバック。HRNet を使用。実験は空手の3姿勢・少人数に限定。
過去の関連研究には PoseNet による空手姿勢分類、OpenPose/FastPose による動作取得、LSTM や ST-GCN による動作系列認識、太極拳の模範動作との比較などがある。
→ **型や単独動作をカメラで評価する技術は、研究としては既にかなり存在する。**

**審判・採点支援**
FST.ai（テコンドーの頭部への蹴りをリアルタイム検出）— 姿勢推定、動作分類、衝撃に関する分析、エッジ端末上の推論。将来的に空手、フェンシング、柔道への応用を想定。
→ これも「キックを上手にする家庭用コーチ」ではなく採点・審判支援。

**試合分析（組技）**
柔道の試合映像から礼・立ち技・寝技・試合中断・選手と審判を自動分類する研究（YOLOv8 による物体検出 + 時間的な動作分類）。ボクシング/MMAの接触数、BJJのポジション、柔道技の分類なども。
→ 関節角度だけでなく、誰と誰が接触しているか、上下関係、身体同士の重なり、技の開始・終了タイミング、競技ルールまで理解する必要がある。**単純な姿勢推定よりかなり複雑。**

**装着型センサー（カメラではない）**
FightCamp は手首・足首トラッカー内部の6軸IMU（加速度計・ジャイロ）。手の動きを最大毎秒1,000回取得し、パンチ数、速度、Output を計算。PunchLab も手首のBluetoothセンサーとサンドバッグ装着のスマホのモーションセンサーで打撃を検出。
→ **現在の格闘技トレーニング製品は、カメラでフォームを見るより、センサーで速さや衝撃を測る方が先に普及している。**
→ センサーは「打撃が発生した」「どれくらい急加速したか」に強いが、ガードが下がった / 肘が開いた / 頭が中心線上に残った / 腰が回っていない / 打った後に構えへ戻っていない、といった全身フォームはほとんど見られない。**ここをカメラで補完する余地がある。**

## 3. 他競技はかなり進んでいる

- **HomeCourt（バスケ）** — iPhone/iPad のカメラだけでシュート数、成功失敗、シュート位置、選手の動き、ドリブルや敏捷性ドリル、リアルタイムフィードバック。外部センサー不要。人物検出 + ボール検出 + ゴール検出 + コート位置推定 + ボール軌道 + シュートイベント判定の統合と考えられる
- **SwingVision（テニス）** — 単一カメラからボール軌道、選手の移動、ショット速度、深さと精度、ラリー数、自動得点、ライン判定、ハイライト。**非常に小さく高速なボールの追跡が中心**
- **Sportsbox AI（ゴルフ）** — 一方向のスイング映像から3Dアバター、骨盤回転、肩の回転、上下半身の分離、身体の移動量、関節角度。独自の競技用3D復元・バイオメカニクスモデルを持つタイプ
- **Uplift** — 2台の iPhone/iPad でマーカーレス全身3D再構築。野球、ソフトボール、テニス、ゴルフ、バスケ、陸上投擲、スクワット等。**二方向からの映像で実際の3D位置を復元しやすくなる**

## 4. 彼らは MediaPipe を使っているのか

概念的には「同じ種類」。多くの製品は次の構造を持つ。

```
カメラ映像 → 人・身体・ボールを検出 → 関節や物体の位置を追跡
→ 時間方向の動きを解析 → 競技固有の意味へ変換 → フィードバック
```

最初の「身体関節を取る」部分は MediaPipe と同じ Human Pose Estimation。**ただし製品全体が MediaPipe でできているわけではない。**

MediaPipe Pose Landmarker が返すのは、人物検出、33個の身体ランドマーク、画像上の座標、推定された3Dワールド座標、セグメンテーションマスク。BlazePose と GHUM をベースに、端末上のリアルタイム・フィットネス用途に最適化。

これで計算できるもの: 肩・肘・手首の角度、腰と肩の回転差、膝の曲がり、左右のスタンス幅、身体の傾き、足の位置、ガード位置、動作速度、打った後の戻り、リズム。**ここまではかなり早く作れる。**

**商用製品は、その上に大きな技術を積んでいる。**

```
1  Person Detection        人を見つける
2  Pose Estimation         関節を見つける            ← 既製ライブラリはここまで
3  Object Detection        ボール、ラケット、グローブ、ゴール
4  Temporal Tracking       前後フレームで同じ人・物を追い続ける
5  Action Recognition      ジャブ、クロス、フック、キックを分類
6  Phase Segmentation      構え、予備動作、加速、接触、戻りを分ける
7  2D-to-3D Reconstruction 一台または複数台から3D化
8  Biomechanics            関節角度、速度、身体連鎖
9  Sport-specific Rules    その競技で何が良い動きか
10 Feedback                映像、音、文章、ドリルへ変換
```

**MediaPipe が担うのは主に 1〜2 の一部。**

**他の選択肢:** MoveNet（17点。スマホやWebで高速）、Apple Vision（iOSで2D・3D身体姿勢）、HRNet（精度重視）、MMPose（多数の姿勢推定モデルを扱う研究・開発基盤）、YOLO Pose（物体検出とキーポイント検出を組み合わせやすい）、OpenPose、各社の独自モデル。

Sportsbox、SwingVision、HomeCourt、Jabbr などは少なくとも主要部分について独自技術と説明しており、**公開情報から「MediaPipe を使っている」とは確認できない。**一部に使っている可能性はあるが断定はできない。

**MediaPipe の3Dには注意。**単一カメラ映像からニューラルネットワークが**推定**した3Dであり、2台以上で三角測量した**測定上の**3D とは違う。
- かなり使える: 左右差、関節角度の傾向、動作のタイミング、身体の相対的位置、前回との比較
- 慎重さが要る: 拳が正確に何cm移動したか、キック速度が何km/hか、衝撃力が何ニュートンか、骨盤が正確に何度回転したか

## 5. 一台のカメラでできること（種目別）

**ボクシング・キックボクシング** — 構えの幅 / ガードの高さ / 顎と頭の位置 / ジャブ時の肩・肘・手首 / クロス時の肩と腰の連動 / 打撃後のガード回復時間 / 頭が中心線に残っている時間 / 左右への体重移動 / コンビネーションのリズム / パンチ間隔 / 疲労によるフォーム変化

**ムエタイ** — キック前のステップ / 軸足の方向 / 膝の軌道 / 股関節の回転 / 上半身のカウンターバランス / 蹴った脚の戻し / ガードの維持 / 左右キックの差

**テコンドー** — 膝を上げるチャンバー / 膝伸展のタイミング / 支持脚の回転 / 頭部の高さに対する足の高さ / 蹴った後の姿勢回復 / 左右差 / 柔軟性と動的コントロールの違い

**空手・型** — 立ち方 / 腰の高さ / 肩と骨盤の方向 / 突きの最終位置 / 引き手 / 技の停止と切れ / 型の順序 / リズムと静止時間

## 6. 一台のカメラでは難しいもの

実際のパンチ威力 / バッグへの正確な衝撃 / 相手に当たったか / 拳の回内・ナックル位置 / 足裏の圧力 / 正確な重心 / 相手と重なった状態 / クリンチ / 柔道の投げ / BJJの細かいポジション / 非常に速い蹴りの瞬間的な足首角度。

これらには、2台以上のカメラ / 60〜240fps撮影 / 手首・足首IMU / バッグの衝撃センサー / 床圧センサー / 競技専用データセット のいずれかが要る。

## 7. 狙える余白

既存製品の多くは **回数、速度、点数、角度、正しい/間違い** を返す。
しかしマーシャルアーツの習得で本当に知りたいのは:

- 力がどこから伝わっているか
- どこで流れが止まったか
- どの瞬間に身体がバラバラになったか
- 打った後に隙が生まれたか
- 力みすぎていないか
- リズムが単調になっていないか
- 自分の身体に合った動きは何か

**ここにグラフィックと音を使える。**例（クロスを打つ）:
足から腰、肩、拳へエネルギーが流れる / 連動が良いと一本の光の鞭になる / 腕だけで打つと肩で光が途切れる / ガードへ戻るまで音が解決しない / 軸が崩れると背景の水平線が傾く / 滑らかなキックは円弧と音がつながる / 力んだキックは粒子が分断される。

→ 試合データ化とも装着型センサーともフォーム分析とも違う、**武術の身体感覚を可視化・可聴化して習得させるシステム**になる。

## 8. 最初に作るなら（プロジェクト固有の案）

スパーリングやBJJの解析から始めない。**MVPは一人で行うシャドーボクシング／キック。**

5つに絞る: ①ジャブ ②クロス ③ジャブ・クロス ④ミドルキック ⑤蹴った後の構えへの復帰

初版は MediaPipe または Apple Vision で十分。そこで技の認識 / 身体連鎖 / バランス / リズム / 戻り / 左右差 / グラフィック / 音響フィードバックを作る。

その後の追加順序: 第2カメラ → IMUトラッカー → バッグセンサー → 専門コーチが作る基準動作 → ユーザー本人の過去動作との比較。
