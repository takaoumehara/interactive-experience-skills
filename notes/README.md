# notes/ — 原資料の置き場

**ここはスキルではない。**`~/.claude/skills/` へ配置されず、`.skill` にも含まれない。

スキルに入れるのは、**案件をまたいで再利用できる判断基準**だけである。特定プロジェクトの企画・競合調査・製品名リスト・実装計画は、スキルに入れると全ユーザーに同じ答えを再生産させることになるので、ここに置く。

各ノートの末尾に「スキルへ反映済み」の対応表があり、何が昇格して何が残ったかを追える。

| ファイル | 内容 |
|---|---|
| `2026-08-embodied-idea-map.md` | 身体 × 描画 × 音響の統合コンセプトノート。触感パレット、身体文法、エンジン戦略、競合分析、33コンセプト、5作ポートフォリオ |
| `2026-08-martial-arts-motion-capture-landscape.md` | マーシャルアーツ × カメラAI の現状調査。種目の構造的難易度、既存製品のカテゴリ、姿勢推定の層構造、狙える余白 |

## 昇格の判断

ノートの内容をスキルへ上げるかは、`CANDIDATES.md` のルーブリックで判断する。

1. 既存の手段では出せない**表現・判断**が出せるか
2. 個人・小規模で到達可能か（到達不能ならその旨を明記できるか）
3. **壊れ方が書けるか**
4. **どの既存記述に接続 or 置換されるか**が言えるか

4を通らないものは上げない。リファレンスが太ると、モデルは読む量を絞り始め、厚くしたことで質が下がる。
