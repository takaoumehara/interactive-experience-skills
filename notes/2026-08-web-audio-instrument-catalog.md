# Web音響 × 身体入力 — 楽器化のカタログと原資料

原資料: Gemini との対話（Web上の音響技術の棚卸し → MediaPipe で身体・顔・指を音にする設計 → 楽器別のマッピング → 空中タップ検出の実装 → 音源・音色カタログ → ブラウザでの実現可能性）。

**このノートはスキルではない。**判断基準として一般化できたものだけを `_extracted/interactive-experience-collective/references/instrument.md` へ昇格させ、ここには昇格しなかった素材（音色カタログ、形式のアイデア、個別のコード）を残す。対応表は末尾。

---

## 1. Web で音を鳴らす手段（棚卸し）

| 層 | 手段 | 位置づけ |
|---|---|---|
| コア | Web Audio API | 標準。オシレータ、フィルタ、`ConvolverNode`、`PannerNode`(HRTF)、`DynamicsCompressorNode` |
| 低遅延DSP | AudioWorklet + WebAssembly | 専用スレッド。C++/Rust/Faust(`wasmjs`)/RNBO(Web export、クラウドコンパイル→wasm) |
| フレームワーク | Tone.js | 事実上の標準。シンセ、エフェクト、`Tone.Sampler`、トランスポート |
| 音楽理論 | Tonal.js | スケール、コード、音程計算 |
| ノードグラフの代替 | Elementary Audio | 宣言的に DSP を書く |
| ライブコーディング | Strudel / Gibber / Flocking | 技術というより**形式**（`solo-scale.md` §2） |
| 外部連携 | Web MIDI API | **Safari / iOS で使えない**（2026-08 時点、実装無し・ロードマップ無し） |
| 再生系 | Howler.js / soundfont-player / tonejs-instruments | SE・BGM の低負荷制御、マルチサンプル音源 |

**ブラウザ固有の制約:** Autoplay policy（ユーザー操作後に `AudioContext` 解錠）、`getUserMedia` は HTTPS か localhost、`SharedArrayBuffer` は cross-origin isolation（COOP/COEP）必須。

## 2. 楽器カテゴリ別のマッピング案（案件ごとに選ぶ素材。スキルには入れない）

| カテゴリ | 音色 | 入力 | 空間インタラクション |
|---|---|---|---|
| 打楽器 | マリンバ、カリンバ、ハンドパン、タングドラム、ガムラン | 手首・指先の速度とジャーク | 空中の板／円を振り下ろす、突く |
| 撥弦・擦弦 | ハープ、箏、ギター、チェロ、シタール | 指先の軌跡、両手の距離 | 光の弦を横切る、つまんで引いて離す、弓を往復 |
| 鍵盤・和音 | フェルトピアノ、Rhodes、チェレスタ | 手のひらの傾き、握り、高さ | 左手でルート、右手の開きでボイシング |
| 気鳴・ドローン | フルート、笙、アコーディオン、パッド | 口の開口度、胸郭の開き（呼吸） | 開くほど倍音とレイヤーが増える |
| 声・合唱 | クワイア、ボコーダー、フォルマント | 口形（母音 F1/F2）、眉、笑顔 | シンセが口の形で歌う／自分の声を和音化 |
| 環境・フォーリー | 水琴窟、焚き火、グラスハープ、風鈴 | 指先の落下点、擦り合わせ、円運動、腕の風速 | 触感パレット 1/6/8（`feel.md`）と対応 |
| ビンテージ・実験 | ベクトル合成、メロトロン、ウェーブテーブル | 両手の中点(XY)、腕の傾き、Z軸の奥行き | 4音色のクロスフェード、テープの揺れ、波形スキャン |

**世界観 × 音源 × スケールの組み合わせ表（企画の初期案出し用）**

| 世界観 | 音源 | トリガー | モジュレーション | スケール |
|---|---|---|---|---|
| Zen / 瞑想 | 水琴窟、ハンドパン、笙 | 指先の加速度 | 両手の距離（残響）、呼吸（ドローン） | 陰旋法 / アケボノ / 平調子 |
| Lo-Fi / チル | フェルトピアノ、エレピ、焚き火 | 手首の振り下ろし | 腕の傾き（テープの揺れ）、口の開閉（フィルタ） | Maj9 / m11 |
| シネマティック | クワイア、オーケストラ、銅鑼 | 指揮のバウンス（BPM） | 両手の広がり（和音展開）、眉（ブラス追加） | リディアン |
| Sci-Fi / 生成的 | ウェーブテーブル、ベル、軌道音 | 軌道の交差 | 重力場、Z軸スキャン | ホールトーン / ペンタトニック |

## 3. 形式のアイデア（打つ以外）

- **空間レーザーハープ** — 光の弦を指が横切る。Karplus-Strong。横切る速度＝撥弦の強さ
- **テルミン / リボン** — 左手が音量、右手が音程、指の震えがビブラート。**音階への可変の引力**が要（→昇格）
- **エア弓** — 左手が位置、右手の往復速度が弓圧と倍音
- **グラニュラー・スキャン** — 空間の位置がグレインの読み取り位置
- **エアDJ** — 円運動＝ビートロール、ピンチ＆ストレッチ＝リバーブとHPFのビルドアップ
- **指揮者モード** — 腕の軌跡の最下点の間隔から BPM を推定し、伴奏のテンポを追従（急変させない）
- **フォルマント／ボコーダー** — 口形から F1/F2 を計算、または自分の声を手の和音フォームで和音化
- **物理演算連動** — 指先から球をこぼし、身体に当たって鳴る（Rapier.js + Three.js + Web Audio）
- **バイノーラル配置** — `PannerNode`(HRTF) の音球を掴んで頭の周りに置く
- **多人数の共鳴** — 2人の手が近づくとうなりが生まれ、重なると最大和音

## 4. 音響の小ネタ（実装時の素材）

- **水滴** — 着水直後に気泡が収縮して**ピッチが上昇する**。下降させると偽物に聞こえる。高Qのバンドパスが陶器の共鳴になる
- **洞窟の残響** — 指数減衰ホワイトノイズで IR を合成すれば「外れない」が、場所らしさは出ない。実空間の IR を1本入れる方が安い差別化（`sound.md` §6）
- **ガムランのうなり（オンバック）** — 微差でデチューンした2音の干渉。1/f のゆらぎ（`pleasure.md` §5）とは別の生命感
- **ハンドパン** — ヘキサトニック／ケルト音階に固定すると乱打しても成立する
- **シマーリバーブ** — 残響に1オクターブ上のピッチシフトを加える。単音を神聖に聞かせる最短路
- **カスケード** — 和音を 10〜30ms ずらす（→昇格）

## 5. 空中タップ検出のコード（原資料。そのままは使わない）

原資料には EMA → 速度 → 加速度 → ジャーク → 状態機械 + クールダウン の TypeScript 実装が含まれる。**構造は正しいが、そのまま使うと以下で壊れる。**この修正点が `instrument.md` §2 の中身になった。

1. 正規化座標の速度はカメラからの距離に依存する。しきい値固定では立ち位置で鳴らなくなる → world landmarks（メートル）か肩幅・手幅で正規化
2. 固定 α の EMA は「速い時に遅れ、遅い時に震える」を両方起こす → one-euro filter
3. 3回微分したジャークはノイズが支配的になる → 各段で平滑化するか、判定は速度と加速度で行う
4. 急減速で判定すると打点が遅い → 下降のピーク速度での予測発音
5. 検出ロスのフレームを速度0にすると復帰時に暴発する
6. デバウンス固定値は連打を殺す → 音楽的な最小音価に合わせる
7. `Atomics.load` は `Float32Array` に使えない（TypeError）
8. AudioWorklet で `sampleRate` を 48000 直書きしない（グローバルにある）

## 昇格しなかったもの

| 見送り | 理由 |
|---|---|
| 音色カタログ（民族楽器、ASMR、ビンテージシンセの一覧） | 案件固有の素材。スキルに入れると全ユーザーに同じ音色を再生産させる |
| 世界観 × 音源のマトリクス | 同上。企画の初期案出しには有用なのでここに残す |
| 形式のアイデア11件（レーザーハープ、指揮者モード等） | コンセプト案であり判断基準ではない |
| 水琴窟・洞窟IRの実装コード | `sound.md` §6 が既に「生成IRは外れないが場所らしさが無い」と判断を述べており、コードは判断を変えない |
| 「すべてブラウザで再現可能」という結論 | `solo-scale.md` と `software.md` が既に扱っている |
